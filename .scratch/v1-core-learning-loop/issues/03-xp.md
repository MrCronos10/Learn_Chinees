# 03: XP

**What to build:** The Learner earns XP for every correctly answered Exercise, whether or not the Lesson becomes a Passed Lesson. The results screen shows XP earned in that Lesson, and the Lesson path shows total XP. XP is saved in Learner Progress.

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] Each correct answer earns XP; a failed Lesson still earns XP for its correct answers
- [ ] Results screen shows XP earned this Lesson
- [ ] Lesson path shows total XP
- [ ] Total XP survives app restart
- [ ] Engine tests cover XP on pass, on fail, and that quitting midway earns nothing
